# retired

本目錄專門放置**未被採用**的型別實作，依淘汰原因分子資料夾區隔。

| 子資料夾 | 用途 |
| --- | --- |
| `deprecated/` | 已被廢棄的型別（曾採用，事後判定不再適用） |
| `outcompeted/` | 在同質實作競逐中敗選的型別（與其他實作同質，最終採用另一份） |

## 使用約定

- 保留原實作與原有註解，不做刪改，以便日後追溯淘汰原因。
- 檔案命名可沿用原本的型別名稱或檔案名稱，如有需要可另加後綴以示區別。
- 若某型別由「敗選」轉為「廢棄」，以最終狀態為準移動至對應子資料夾。
- 採用多級目錄結構，便於管理與追溯。
- 註解中標記勝出者，並註明淘汰原因。
